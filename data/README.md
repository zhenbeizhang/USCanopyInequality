# Data placeholder

No full analysis frames, full-resolution rasters or restricted third-party
inputs are included in this directory. Lightweight derived neighbourhood
GeoJSON layers used by the interactive atlas are stored under
`atlas/public/neighbourhoods/` and documented in
`atlas/docs/data_dictionary.md`.

The study data will be released as a separate versioned record containing
frozen analysis frames, figure source data, data dictionaries, permitted
derived spatial products and checksums. See ../docs/data_contract.md and
../docs/release_plan.md for the planned interface. Do not place private data,
raw licensed imagery or model checkpoints in this Git repository.

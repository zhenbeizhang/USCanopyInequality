# Code availability statement

Code used for canopy inference, census aggregation, social-canopy modelling,
surface-temperature modelling, neighbourhood classification, equal-budget
allocation comparisons, figure generation and quality-control audits is
available at https://github.com/zhenbeizhang/USCanopyInequality. The minimum
supporting dataset is available from Zenodo at
https://doi.org/10.5281/zenodo.21976810. It contains frozen analysis-unit
ledgers, source data for all main and Supplementary figures and tables,
compact model and bootstrap outputs, random seeds, checksums and
licence-permitted neighbourhood-level derived spatial data. Raw
high-resolution imagery and full-resolution canopy masks are not redistributed
because the authors do not hold consistent redistribution rights and complete
upstream metadata for those inputs. Model-development patches and checkpoints
are outside the scope of the minimum supporting dataset.

The GitHub repository is the canonical code location. The Zenodo DOI identifies
the supporting dataset and must not be described as a DOI for the software.

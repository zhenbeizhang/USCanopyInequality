# Code availability statement

## Before archival DOI assignment

Code used for canopy inference, census aggregation, social-canopy modelling,
surface-temperature modelling, neighbourhood classification, equal-budget
allocation comparisons, figure generation and quality-control audits is
available at https://github.com/zhenbeizhang/USCanopyInequality. The frozen
analysis data and permitted derived spatial products will be released as a
separate data record. Raw third-party imagery will be shared only where source
licences permit redistribution.

## After software and data archiving

Replace the bracketed fields before submission:

> Code used in this study is available at
> https://github.com/zhenbeizhang/USCanopyInequality and has been archived at
> [software repository and DOI]. Frozen analysis frames, figure source data and
> permitted derived spatial products are available at [data repository and
> DOI]. Raw third-party imagery is not redistributed where prohibited by the
> source licence; source, access and rights information are provided in the
> data record.

Do not cite a DOI until the archive has issued it and the deposited release has
been checked against the GitHub tag.
